# 配件出入库管理系统

一个简洁实用的配件库存管理网页应用，支持：

- 配件新增与维护
- 出库/入库记录
- 库存实时统计
- 查询与筛选
- 本地数据持久化（浏览器 localStorage）

## 运行方式

1. 下载或拉取本项目。
2. 在项目根目录中直接打开 `index.html` 即可使用。
3. 也可以使用本地静态服务器运行：

```bash
python -m http.server 8000
```

然后访问：

`http://localhost:8000`

## 功能说明

- 配件编码、名称、类别、单位、库存数量
- 入库：增加库存
- 出库：减少库存
- 自动记录每次操作时间、数量、原因
- 可按名称或编码过滤配件
- 数据保存在浏览器中，刷新后不丢失

## 适用场景

- 维修部件管理
- 生产车间配件管理
- 仓储出入库登记
- 小型企业库存盘点
